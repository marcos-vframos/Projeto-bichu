# Matriz de Equivalência: Interface Visual vs. Chat (API & MCP)

Esta matriz relaciona cada ação disponível nas telas do aplicativo **Meu Bichu** com sua respectiva rota na API REST e sua ferramenta correspondente no Servidor MCP remoto (JSON-RPC 2.0), detalhando as coleções do banco afetadas e notas técnicas de paridade.

---

| Módulo / Ação na Interface                                   | Rota API REST (`/backend/v1/*`)               | Tool MCP (`tools/call`)  | Coleção & Efeito no PocketBase                                                 | Observações de Paridade e Regras                                                                                                                 |
| ------------------------------------------------------------ | --------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Pets — Listar Cães** (`/dogs`)                             | `GET /backend/v1/dogs`                        | `listar_meus_pets`       | `dogs` (leitura)                                                               | Paridade total. Filtra por `user` autenticado ou `device_key`. Ordena por `-created`.                                                            |
| **Pets — Ver Detalhes** (`/dogs/:id`)                        | `GET /backend/v1/dogs/{id}`                   | `obter_pet`              | `dogs` (leitura por ID)                                                        | Retorna peso, raça, porte, castração, microchip e dados biométricos.                                                                             |
| **Pets — Cadastrar Novo** (`/dogs/new`)                      | `POST /backend/v1/dogs`                       | `criar_pet`              | `dogs` (create) + `weight_logs` (create)                                       | Registra o pet e grava automaticamente o primeiro peso no histórico com a data atual.                                                            |
| **Pets — Editar Cadastro** (`/dogs/:id/edit`)                | `PATCH /backend/v1/dogs/{id}`                 | `editar_pet`             | `dogs` (update)                                                                | Valida autorização de propriedade do pet (se atribuído a um usuário).                                                                            |
| **Pets — Excluir Pet** (`/dogs/:id`)                         | `DELETE /backend/v1/dogs/{id}`                | `excluir_pet`            | `dogs` (delete)                                                                | Remove o cão. Exige validação de autorização quando pertence ao usuário logado.                                                                  |
| **Peso — Registrar Pesagem** (Modal/Aba `/weight`)           | `POST /backend/v1/weight-logs`                | `registrar_peso`         | `weight_logs` (create) + `dogs` (update)                                       | Cria registro histórico e sincroniza atômica e imediatamente o campo `weight_kg` em `dogs`.                                                      |
| **Peso — Listar Histórico** (`/weight`)                      | `GET /backend/v1/weight-logs?dog={id}`        | `listar_pesos`           | `weight_logs` (leitura)                                                        | Lista evolução de peso ordenada por data (`logged_at`).                                                                                          |
| **BCS — Avaliação Corporal** (`/bcs`)                        | `POST /backend/v1/bcs-evaluations`            | `registrar_bcs`          | `bcs_evaluations` (create) + `feeding_plans` (create/update) + `dogs` (update) | Aplica as equações oficiais NRC/WSAVA. Se `auto_adjust=true`, inativa planos anteriores, cria novo plano ativo e ajusta `body_condition` no cão. |
| **BCS — Histórico de Avaliações** (`/bcs`)                   | `GET /backend/v1/bcs-evaluations?dog={id}`    | -                        | `bcs_evaluations` (leitura)                                                    | Histórico de escores (1 a 9) e categorias (abaixo, ideal, sobrepeso, obesidade).                                                                 |
| **Alimentação — Plano Ativo** (`/feeding`)                   | `GET /backend/v1/feeding-plans?dog={id}`      | `obter_plano_alimentar`  | `feeding_plans` (leitura)                                                      | Retorna gramas/dia, calorias diárias, meta (`manter`/`emagrecer`/`ganhar`) e divisão em refeições.                                               |
| **Alimentação — Ajustar Plano** (`/feeding`)                 | `POST /backend/v1/feeding-plans`              | `ajustar_plano`          | `feeding_plans` (create/update)                                                | Recalcula porção diária com base na densidade calórica da ração (kcal/kg) e nível de atividade.                                                  |
| **Rações — Catálogo Curado** (`/foods`)                      | `GET /backend/v1/foods`                       | -                        | `foods` (leitura)                                                              | Catálogo oficial das marcas do mercado brasileiro.                                                                                               |
| **Rações — Cadastrar Ração** (`/compare-foods`)              | `POST /backend/v1/user-foods`                 | `registrar_racao`        | `user_foods` (create)                                                          | Registra nova ração e níveis de garantia no banco colaborativo anônimo (LGPD).                                                                   |
| **Rações — Listar Colaborativas** (`/compare-foods`)         | `GET /backend/v1/user-foods`                  | -                        | `user_foods` (leitura)                                                         | Rações cadastradas pelos tutores.                                                                                                                |
| **Saúde — Listar Procedimentos** (`/health`)                 | `GET /backend/v1/health-events?dog={id}`      | `listar_registros_saude` | `health_events` (leitura)                                                      | Vacinas, vermífugos, medicamentos, consultas e cirurgias.                                                                                        |
| **Saúde — Adicionar Procedimento** (`/health`)               | `POST /backend/v1/health-events`              | `criar_registro_saude`   | `health_events` (create)                                                       | Valida enums de tipos permitidos (`consulta`, `vacina`, `medicacao`, `tratamento`, `evento`).                                                    |
| **Saúde — Atualizar/Concluir** (`/health`)                   | `PATCH /backend/v1/health-events/{id}`        | -                        | `health_events` (update)                                                       | Marca como concluído ou atualiza posologia.                                                                                                      |
| **Saúde — Excluir Procedimento** (`/health`)                 | `DELETE /backend/v1/health-events/{id}`       | -                        | `health_events` (delete)                                                       | Remove registro da saúde assistida.                                                                                                              |
| **Rotina — Listar Agenda** (`/health` aba rotina)            | `GET /backend/v1/routine-events?dog={id}`     | `listar_eventos_rotina`  | `pet_routine_events` (leitura)                                                 | Compromissos e horários de passeios, treinos e banhos.                                                                                           |
| **Rotina — Agendar Atividade** (`/health` aba rotina)        | `POST /backend/v1/routine-events`             | `criar_evento_rotina`    | `pet_routine_events` (create)                                                  | Registra atividade com horários de início/fim e recorrência.                                                                                     |
| **Rotina — Atualizar/Concluir** (`/health` aba rotina)       | `PATCH /backend/v1/routine-events/{id}`       | -                        | `pet_routine_events` (update)                                                  | Altera status de conclusão da tarefa ou notas.                                                                                                   |
| **Rotina — Excluir Evento** (`/health` aba rotina)           | `DELETE /backend/v1/routine-events/{id}`      | -                        | `pet_routine_events` (delete)                                                  | Remove o compromisso da agenda do pet.                                                                                                           |
| **Profissionais — Buscar** (`/professionals`)                | `GET /backend/v1/professionals`               | `listar_profissionais`   | `professionals` (leitura)                                                      | Ordenação automática por média de avaliação e volume de reviews.                                                                                 |
| **Profissionais — Detalhe & Reviews** (`/professionals/:id`) | `GET /backend/v1/professionals/{id}`          | -                        | `professionals` + `professional_reviews` (leitura)                             | Detalhes do profissional e comentários deixados por outros tutores.                                                                              |
| **Profissionais — Avaliar** (`/professionals/:id`)           | `POST /backend/v1/professionals/{id}/reviews` | `avaliar_profissional`   | `professional_reviews` (create) + `professionals` (update)                     | Exige usuário logado. Recalcula atômica e imediatamente a média aritmética no profissional.                                                      |
| **Social — Feed de Posts** (`/feed`)                         | `GET /backend/v1/posts`                       | `listar_posts`           | `posts` + `post_likes` (leitura)                                               | Publicações comunitárias em ordem cronológica reversa.                                                                                           |
| **Social — Publicar no Feed** (`/feed`)                      | `POST /backend/v1/posts`                      | `criar_post`             | `posts` (create)                                                               | Exige autenticação. Vincula o nome do tutor e o pet.                                                                                             |
| **Social — Curtir Post** (`/feed`)                           | `POST /backend/v1/posts/{id}/likes`           | `curtir_post`            | `post_likes` (create/delete) + `posts` (update)                                | Toggle like. Incrementa ou decrementa atômico do contador de curtidas.                                                                           |
| **Social — Comentar Post** (`/feed`)                         | `POST /backend/v1/posts/{id}/comments`        | `comentar_post`          | `post_comments` (create) + `posts` (update)                                    | Incrementa `comments_count` e registra comentário com nome do autor.                                                                             |
| **Social — Seguir Tutor** (`/profile/:id`)                   | `POST /backend/v1/follows`                    | `seguir`                 | `follows` (create/delete)                                                      | Toggle follow entre tutores.                                                                                                                     |
| **Descobrir — Tinder Canino / Match** (`/discover`)          | `POST /backend/v1/matches`                    | `registrar_match`        | `pet_matches` (upsert)                                                         | Registra `like` ou `pass`. Detecta match recíproco imediato (`is_mutual = true`).                                                                |
| **Descobrir — Meus Matches** (`/discover`)                   | `GET /backend/v1/matches`                     | -                        | `pet_matches` (leitura)                                                        | Lista matches confirmados do usuário.                                                                                                            |
| **Conta — Login com Senha** (`/login`)                       | `POST /backend/v1/auth/login`                 | -                        | `users` (auth)                                                                 | Emite token JWT e retorna dados cadastrais do usuário e perfil do tutor.                                                                         |
| **Conta — Meu Usuário**                                      | `GET /backend/v1/auth/me`                     | -                        | `users` + `tutor_profiles` (leitura)                                           | Informações da sessão autenticada do token atual.                                                                                                |
